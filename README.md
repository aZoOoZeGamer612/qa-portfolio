## About the reports in this portfolio

- `PSP-OT2-001` is reconstructed from a UI problem I personally observed while testing an experimental Oregon Trail II PSP build. Exact build metadata and reproduction counts were not recorded at the time, so the report says so instead of inventing them.
- The Sapience and Haraj Plus documents are **sample test cases**, not claims that those bugs currently exist in released versions. They demonstrate how I would structure testing around real features.
